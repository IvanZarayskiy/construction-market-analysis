# Данные

В директории содержатся подготовленные данные, использованные для анализа строительной отрасли.

## Источник

Данные получены из официального ресурса бухгалтерской отчётности Федеральной налоговой службы России.

В выборку включены организации с ОКВЭД 41.20 — строительство жилых и нежилых зданий.

## Файлы

### `data/construction_data_clean.csv`

Основной очищенный датасет исследования.

Содержит финансовые показатели организаций за несколько отчётных периодов.

Основные столбцы:

| Столбец      | Описание                                     |
| ------------ | -------------------------------------------- |
| `id`         | Идентификатор организации в источнике данных |
| `name`       | Наименование организации                     |
| `inn`        | ИНН организации                              |
| `region`     | Регион регистрации                           |
| `period`     | Отчётный год                                 |
| `revenue`    | Выручка, тыс. руб.                           |
| `net_profit` | Чистая прибыль, тыс. руб.                    |
| `ebit`       | EBIT, тыс. руб.                              |

### `data/summary.csv`

Сводная таблица с основными характеристиками сформированной выборки и результатами предварительного анализа.

## Обработка данных

Перед проведением анализа были выполнены:

* проверка структуры данных;
* проверка пропущенных значений;
* удаление дубликатов;
* исключение некорректных повторных записей;
* приведение типа отчётного периода к числовому;
* расчёт EBIT;
* формирование итогового очищенного датасета.

Финансовые показатели представлены в тысячах рублей.
